## Bubble Sort

### Approach

During every pass, compare adjacent values. If the left value is greater than the right value, swap them. Return the sorted array.

### Complexity

- **Time:** `O(n^2)` in the best, average, and worst cases. The nested loops perform `(n - 1) + (n - 2) + ... + 1` adjacent comparisons.
- **Auxiliary space:** `O(1)`, because only loop variables and one temporary value are maintained. The input array is rearranged in place.

### Implementation

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> bubbleSort(vector<int>& arr) {
        int n = arr.size();

        for (int pass = 0; pass < n - 1; pass++) {
            for (int current = 0; current < n - pass - 1; current++) {
                if (arr[current] > arr[current + 1]) {
                    swap(arr[current], arr[current + 1]);
                }
            }
        }

        return arr;
    }
};
```
