## Quick Sort

### Approach

For each partition, select a pivot and place it in its correct sorted position. Move values smaller than or equal to the pivot to its left and greater values to its right. Recursively sort the ranges on either side of the pivot, then return the sorted array.

### Complexity

- **Time:** `O(n log n)` on average because each partition scans the active range once, and balanced partitions create about `log n` levels. The worst case is `O(n^2)` when the pivot is repeatedly the smallest or largest value.
- **Auxiliary space:** `O(log n)` on average for the recursion stack. In the worst case, the stack uses `O(n)` space when partitions are completely unbalanced. Partitioning does not create an additional array proportional to `n`.

### Implementation

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> quickSort(vector<int>& arr) {
        int n = arr.size();
        solve(arr, 0, n - 1);
        return arr;
    }

private:
    void solve(vector<int>& arr, int low, int high) {
        if (low >= high) {
            return;
        }

        int pivotIndex = partitionArray(arr, low, high);

        solve(arr, low, pivotIndex - 1);

        solve(arr, pivotIndex + 1, high);
    }

    int partitionArray(vector<int>& arr, int low, int high) {
        int pivot = arr[high];
        int smallerIndex = low - 1;

        for (int current = low; current < high; current++) {
            if (arr[current] <= pivot) {
                smallerIndex++;
                swap(arr[smallerIndex], arr[current]);
            }
        }

        swap(arr[smallerIndex + 1], arr[high]);
        return smallerIndex + 1;
    }
};
```
