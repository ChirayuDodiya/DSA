## Selection Sort

### Approach

During every pass, select the smallest value from the unsorted part and place it at the first position of that part. Return the sorted array.

### Complexity

- **Time:** `O(n^2)` in the best, average, and worst cases. The exact comparison count is `(n - 1) + (n - 2) + ... + 1 = n(n - 1) / 2`.
- **Auxiliary space:** `O(1)`, because only index and temporary variables are maintained. The input array is rearranged in place.

### Implementation

```cpp
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> selectionSort(vector<int>& arr) {
        int n = arr.size();

        for (int boundary = 0; boundary < n - 1; boundary++) {
            int minIndex = boundary;

            for (int current = boundary + 1; current < n; current++) {
                if (arr[current] < arr[minIndex]) {
                    minIndex = current;
                }
            }

            if (minIndex != boundary) {
                swap(arr[boundary], arr[minIndex]);
            }
        }

        return arr;
    }
};
```
